# 🍎 Prep — Apple Developer Academy

Repositório dedicado ao estudo e resolução prática de exercícios de **Lógica de Programação, Algoritmos e Estruturas de Dados Básicas**, estruturado com base nos conteúdos programáticos do processo seletivo da **Apple Developer Academy**.

---

## 🎯 Objetivo

O objetivo deste projeto é desenvolver raciocínio lógico estruturado, domínio de controle de fluxo, resolução de problemas e manipulação de coleções de dados (strings e vetores), garantindo preparação prática para o teste técnico de programação.

---

## 📚 Conteúdos Programáticos e Módulos

O repositório está organizado em módulos por assuntos do edital. Cada pasta contém os seus respetivos exercícios detalhados e soluções:

| Módulo | Descrição do Conteúdo | Status |
|---|---|---|
| 📐 **[01. Variáveis e Constantes](./01-variaveis-e-constantes)** | Variáveis, constantes, operadores aritméticos, entrada e saída de dados | ⏳ Em andamento |
| 🔀 **[02. Condições](./02-condicoes)** | Estruturas de seleção (`if`, `else`, `switch`), operadores lógicos e validações | ⏳ Em andamento |
| 🔄 **[03. Repetições](./03-repeticoes)** | Laços de repetição (`for`, `while`, `do-while`), acumuladores e séries | ⏳ Em andamento |
| 🔤 **[04. Strings](./04-strings)** | Manipulação de texto, percorrimento por índices, pesquisas e validações | ⏳ Em andamento |
| 🔢 **[05. Vetores](./05-vetores)** | Arrays unidimensionais, pesquisas, ordenação e manipulação por índice | ⏳ Em andamento |
